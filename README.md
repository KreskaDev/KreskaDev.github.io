# What is the truth?

Personal tech blog by [KreskaDev](https://github.com/KreskaDev). Live at [kreskadev.github.io](https://kreskadev.github.io/).

Essays on probability, reasoning, and the gap between what we measure and what we know.

## Tech

- Next.js 16 (App Router, static export)
- TypeScript, Tailwind CSS 4
- MDX with KaTeX math + Recharts
- Deployed to GitHub Pages

## Development

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # static export to out/
npm run test     # vitest
npm run lint     # eslint
```
