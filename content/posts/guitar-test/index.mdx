# Guitar Fretboard — widget sandbox

Strona robocza dla iteracji v5-09..v5-13. v5-09 dostarczył bazowy `<Fretboard />`
read-only. v5-11 dodaje inteligentny wrapper `<FretboardVisualizer />` ze skale,
akordy, click-to-highlight i sample-based audio playback (acoustic guitar nylon
z biblioteki Gleitzman MIDI.js FatBoy, CC-BY-SA 3.0).

## v5-09 baseline — `<Fretboard />` (base, read-only)

Bazowy widget — voicing x32010 (open C major). Strony 5..1 = positions
[fret 3, 2, 0, 1, 0]; struna 0 (low E) jest tłumiona w tym voicingu — v5-09
read-only nie renderuje muted strings, więc po prostu nie pojawia się w `notes`
array. v5-13 ChordAnalyzer dodaje muted rendering jako × przed nutem.

      { string: 1, fret: 3 },
      { string: 2, fret: 2 },
      { string: 3, fret: 0 },
      { string: 4, fret: 1 },
      { string: 5, fret: 0 },
    ]}
  />
</div>

## v5-13 UC5 — Preset shape przez `chord` prop

ChordAnalyzer ma **dwa wejścia** — `shape` (explicit voicing, jak w UC1-4) i `chord`
(preset load z internal `chord-shapes.ts` library — 13 curated voicings: 5 open major,
3 open minor, barre F, 4 jazz seventh). Tu ładujemy A minor preset przez `chord` prop —
wrapper rozwiązuje `{root:'A',type:'min'}` do shape `x02210` z biblioteki. Identyczny
efekt jak gdyby autor zapisał `shape={[null,0,2,2,1,0]}`, ale czytelniejszy MDX.

## v5-13 UC6 — Jazz cadence ii-V-I w C-dur (Dm7 → G7 → Cmaj7)

Klasyczna kadencja jazzowa — minor seventh na drugim stopniu, dominant seventh na piątym,
major seventh na pierwszym. Wszystkie trzy akordy mają charakterystyczne brzmienia czwórek
(tetrad): m7 (smutny/relaxed), 7 (bluesowy tension), maj7 (jasny/resolved). Każdy widget
wyświetla degrees breakdown — łatwo prześledzić jak `m7` i `7` różnią się tercją (m3 vs 3),
a `maj7` od `7` siódemką (7 vs m7).

## v5-13 UC7 — Rodzina C (extension chain)

Ten sam root C, ale dodajemy kolejne nuty extension: triada `C` → siódemka `Cmaj7` →

## v5-13 UC8 — Symetria dim7 (jedna voicing, cztery nazwy)

Akord zmniejszony septymowy (`dim7`) ma symetryczną strukturę — wszystkie cztery
interwały to małe tercje (3 semitony). Konsekwencja: ten sam voicing rozpoznajemy
jako **cztery różne akordy** zależnie od którą nutę uznamy za root. Voicing
`x23130` w Standard tuning daje pitches `B-F-G#-D` — to równocześnie Ddim7, Fdim7,
G#dim7 i Bdim7. Algorithm zwraca primary "D dim7" (pierwszy enumerowany), ale w
ranked output wszystkie cztery są obecne z identyczną confidence 1.00. W jazzie
kontekst tonalny (poprzedni akord, kierunek głosu basu) decyduje którą nazwę użyć.

<ChordAnalyzer id="dim7-symmetry" shape={[null, 2, 3, 1, 3, null]} />

## v5-13 UC9 — Inwersje basowe (ta sama voicing, trzy interpretacje)

Pojedynczy open C voicing `x32010` zawiera pitches `C-E-G-C-E`. Zależnie od tego
**która struna nosi bass note**, czytelnik słyszy inną inwersję — root position
(bass=C), pierwsza inwersja (bass=E), druga inwersja (bass=G). Wrapper kontroluje
to przez `rootStringIndex` — same shape, three names: "C maj", "C/E", "C/G".
Pedagogicznie demonstruje że *słownik* slash chord ("ułamkowy zapis") to nie
zawsze realny voicing change, czasem tylko reinterpretacja basu.

## v5-14 — Intervals accordion + degree labels

Każdy widget powyżej dostał teraz dwie nowe funkcje. Pod fretboardem znajdziesz
`Show intervals` — kliknięcie rozwija akordeon z listą nut, interwałami od pierwiastka
i wykrytą nazwą skali/akordu (a jeśli detekcja jest niejednoznaczna, zobaczysz też
alternatywne odczytanie). Obok jest przycisk `Show degrees` — przełącza etykiety na
fretboardzie między nazwami nut (C, E, G) a stopniami od pierwiastka (R, 3, 5).
W ChordAnalyzer akordeon pokazuje też przycisk `▶ Play chord` — odgrywa wszystkie
nuty akordu jednocześnie. Akordeon i przełącznik etykiet są niezależne — możesz
mieć rozwinięty akordeon bez stopni na fretboardzie i odwrotnie.

## v5-15 — Notation widget (VexFlow)

Drugi widget w music vertical: read-only renderowanie nutacji muzycznej (pięciolinia +
nuty z rytmem, key signature, time signature). Pod nutami slider BPM (40-240, default 90
*moderato*) + przycisk ▶ Play który odtwarza ciąg nut sekwencyjnie z timing wynikającym
z notation durations. Podczas odtwarzania aktualnie grana nuta jest podświetlana —
edukacyjny mapping rytmu ↔ pozycji wizualnej. Notation jest **data-driven**: autor wpisuje
JSON `Note[]` bezpośrednio w MDX (struktura: pitch, duration, dotted, rest, tied, voice,
articulation, ornament, tuplet). Forward-compat: kolejna iteracja doda scale-on-fretboard
konsumujący ten sam `Note[]` jako dwie projekcje (notation + fretboard graph). Poniższe
demo pokazują wprowadzone rytmy + features.

## v5-16 ScaleOnFretboard — wizualizacja skal na gryfie

Widget `<ScaleOnFretboard/>` mapuje sekwencję nut (`Note[]`, ten sam shape co `<Notation/>`)
na pozycje fretboardu. Strzałki łączą kolejne pozycje (default `showArrows=true`); Play
odgrywa skalę z BPM-driven timing reuse'ując shipped `notation-timing` + `audio-sequence`
(ADR-049 + ADR-054 third consumer chain). Gdy `Note.position` jest pominięte, widget
używa `note-positions.ts` naïve first-match (lowest fret); explicit `position` w MDX
nadpisuje auto-pick (D7 demo). Per-instance state (ADR-011) — wiele widgetów na stronie
ma osobne BPM, playback i highlight.

Mobile: fretboard >10 fretów wymaga horizontal scroll na 360px viewport (analog v5-09
Fretboard); overlay strzałek + highlight ring scroll'ują razem z base SVG (single
overflow container).
